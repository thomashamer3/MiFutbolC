Cambios destacados v4.2

  • Fecha con dia de semana en listados de partidos, lesiones y finanzas.
  • Limpieza completa de consola en Windows para evitar residuos visuales.
  • Ajustes de compilacion MinGW con librerias de enlace recomendadas.
  • Rutas de base de datos mas seguras y legibles con snprintf.
  • Flujo de imagenes reforzado para camisetas (seleccion, resolucion y feedback).
  • Ciclo activa/inactiva para camisetas y canchas sin perder historial.
  • Instalacion por consola en Windows con el script install.ps1.
